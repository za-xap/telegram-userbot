# [telegram-userbot](https://t.me/Za_XaP "My Telegram profile")
### 👤🤖 Telegram userbot that updates the bio every minute with the same text and updates current local time.
_It also logs all incoming private messages from users in one group and forwards a message in another if it was deleted. The bot sends pings to healthchecks.io to be informed of any server drops where the bot is hosted._

_Rename **config.example.py** to **config.py** and configure it before running **user.py**._
